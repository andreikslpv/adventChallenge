# AI Chat Application

Приложение для работы с ИИ через API z.ai (GLM-4)

## Особенности

- ✅ Диалог для настройки системного промпта при запуске
- ✅ Чат-интерфейс с историей сообщений
- ✅ Расширенные настройки запросов к ИИ:
  - Настройка температуры (от 0.0 до 2.0)
  - Ограничение максимальной длины ответа в символах
  - Ограничение максимальной длины ответа в токенах (1-8192)
  - Выбор типа ответа (текст или JSON)
  - Настройка стоп-слова для остановки генерации
- ✅ Отображение сообщений пользователя и ответов ИИ
- ✅ Обработка ошибок с уведомлениями
- ✅ Логирование сетевых запросов для debug-сборок

## Технологии

- **Kotlin** - язык разработки
- **Jetpack Compose** - UI фреймворк
- **Kotlinx Serialization** - JSON парсинг
- **Ktor Client** - HTTP клиент с OkHttp engine и логированием
- **Koin** - Dependency Injection
- **ViewModel** - управление состоянием

## Настройка

1. Добавьте свой API ключ z.ai в файл `local.properties`:

```properties
zaiApiKey=ВАШ_API_КЛЮЧ
```

2. Соберите и запустите проект

## Использование

1. При первом запуске появится диалоговое окно "Кто я?"
2. Введите системный промпт (описание роли ИИ)
3. Настройте параметры запроса:
   - **Температура**: 0.0 - более консервативные ответы, 2.0 - более креативные
   - **Макс. длина в символах**: ограничение на количество символов в ответе (опционально)
   - **Макс. длина в токенах**: ограничение на количество токенов (1-8192, опционально)
   - **Тип ответа**: текстовый или JSON формат
   - **Стоп слово**: слово для остановки генерации при его появлении (опционально)
4. Нажмите "Сохранить" для сохранения настроек
5. Введите свой вопрос в поле ввода на главном экране
6. Нажмите кнопку отправки или Enter

## Изменение системного промпта

Нажмите на иконку настроек (⚙️) в правом верхнем углу, чтобы изменить системный промпт и температуру.

## API Endpoint

Используется API GLM-4:
- URL: `https://api.z.ai/api/paas/v4/chat/completions`
- Модель: `glm-4.7-flashx`

## Логирование

Для debug-сборок включено детальное логирование сетевых запросов через Ktor Logging Plugin.
