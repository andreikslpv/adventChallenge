# AI Chat Application

Приложение для работы с ИИ через API z.ai (GLM-4)

## Особенности

- ✅ Чат-интерфейс с историей сообщений
- ✅ Работа с несколькими AI-агентами:
  - Добавление, удаление и настройка агентов
  - Горизонтальный список агентов под топбаром
  - Кнопка "Отправить всем" для одновременного запроса ко всем агентам
  - Каждое сообщение ИИ содержит системный промт агента
- ✅ Расширенные настройки запросов к ИИ для каждого агента:
  - Настройка системного промпта
  - Настройка температуры (от 0.0 до 2.0)
  - Ограничение максимальной длины ответа в символах
  - Ограничение максимальной длины ответа в токенах (1-8192)
  - Выбор типа ответа (текст или JSON)
  - Настройка стоп-слова для остановки генерации
- ✅ Отображение сообщений пользователя и ответов ИИ
- ✅ Копирование текста сообщения при долгом нажатии
- ✅ Очистка текущей сессии через меню настроек
- ✅ Обработка ошибок с уведомлениями
- ✅ Логирование сетевых запросов для debug-сборок

## Технологии

- **Kotlin** - язык разработки
- **Jetpack Compose** - UI фреймворк
- **Kotlinx Serialization** - JSON парсинг
- **Ktor Client** - HTTP клиент с OkHttp engine и логированием
- **Koin** - Dependency Injection
- **ViewModel** - управление состоянием

## Настройка

1. Добавьте свой API ключ z.ai в файл `local.properties`:

```properties
zaiApiKey=ВАШ_API_КЛЮЧ
```

2. Соберите и запустите проект

## Использование

### Работа с агентами

При запуске приложения автоматически создается один агент с пустым системным промптом:

1. **Добавление агента**: нажмите на кнопку с плюсом в списке агентов
2. **Настройка агента**: нажмите кнопку "Настроить" на карточке агента, чтобы открыть диалоговое окно с настройками
3. **Удаление агента**: нажмите на кнопку удаления (иконка корзины) на карточке агента (доступно, если агентов больше одного)
4. **Выбор агента**: нажмите на карточку агента, чтобы сделать его активным (выделится цветом)
5. **Отправка всем**: если агентов больше одного, рядом с кнопкой "Отправить" появится кнопка "Отправить всем" для одновременного запроса ко всем агентам

### Настройка агента

В диалоге настроек вы можете:

- **Системный промпт**: описание роли ИИ (например, "Ты полезный ассистент по программированию")
- **Температура**: 0.0 - более консервативные ответы, 2.0 - более креативные
- **Макс. длина в символах**: ограничение на количество символов в ответе (опционально)
- **Макс. длина в токенах**: ограничение на количество токенов (1-8192, опционально)
- **Тип ответа**: текстовый или JSON формат
- **Стоп слово**: слово для остановки генерации при его появлении (опционально)

### Чат

1. Выберите агента из списка или используйте текущего
2. Введите свой вопрос в поле ввода на главном экране
3. Нажмите кнопку "Отправить" для отправки выбранному агенту или "Отправить всем" для одновременного запроса ко всем агентам
4. Ответы ИИ будут отображаться с указанием системного промпта агента
5. Для очистки сессии нажмите на меню настроек (⚙️) в правом верхнем углу и выберите "Очистить текущую сессию"

## Дополнительные возможности

### Копирование сообщений

Для копирования текста любого сообщения (пользователя или ИИ) в буфер обмена:
- Удерживайте долгое нажатие на сообщении

### Очистка сессии

Для удаления всех сообщений из истории чата:
1. Нажмите на меню настроек (⚙️) в правом верхнем углу
2. Выберите пункт "Очистить текущую сессию"

## API Endpoint

Используется API GLM-4:
- URL: `https://api.z.ai/api/paas/v4/chat/completions`
- Модель: `glm-4.7-flashx`

## Логирование

Для debug-сборок включено детальное логирование сетевых запросов через Ktor Logging Plugin.
