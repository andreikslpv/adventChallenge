# AI Chat Application

Мультиплатформенное приложение для работы с ИИ-агентами через API z.ai (GLM-4) и OpenAI (GPT-4)

## Документация

- [Работа с агентами](docs/agents.md) — подробное описание принципов работы с агентами, настройки параметров и обработки запросов
- [Суммаризация сессий](docs/summarization.md) — подробное описание механизма сжатия истории сообщений и инкрементальной суммаризации

## Особенности

### Агенты
- ✅ **Мультиагентная система**: работа с несколькими AI-агентами одновременно
  - Добавление, удаление и настройка агентов
  - Горизонтальный список агентов под топбаром
  - Кнопка "Отправить всем" для одновременного запроса ко всем агентам
  - Каждое сообщение ИИ содержит системный промт агента
- ✅ **Расширенные настройки агентов**:
  - Настройка системного промпта (роль и поведение ИИ)
  - Температура (0.0 - 2.0): от консервативных до креативных ответов
  - Выбор модели: GLM-4.5-flash, GLM-4.6, GLM-4.7
  - Максимальная длина ответа в токенах (1-8192)
  - Тип ответа: текст или JSON
  - Стоп-слово для остановки генерации

### Сессии
- ✅ **Управление сессиями**: создание, выбор и удаление сессий
- ✅ **Автоматическое именование**: сессии получают название на основе первого сообщения
- ✅ **Суммаризация истории**: инкрементальное сжатие длинных бесед для экономии токенов
- ✅ **Персистентность**: сохранение агентов, сообщений и настроек между запусками

### Интерфейс
- ✅ **Современный UI на Jetpack Compose**: адаптивный интерфейс для всех платформ
- ✅ **Чат-интерфейс с историей**: отображение сообщений пользователя и ответов ИИ
- ✅ **Копирование сообщений**: долгое нажатие для копирования текста в буфер обмена
- ✅ **Очистка сессии**: быстрое удаление всех сообщений через меню настроек
- ✅ **Обработка ошибок**: уведомления о проблемах с сетью и API

### Технологии
- ✅ **Kotlin Multiplatform**: единая кодовая база для Desktop, Android и Web
- ✅ **Jetpack Compose**: современный UI-фреймворк
- ✅ **Koin**: Dependency Injection
- ✅ **Room (Android) / SQLite (Desktop)**: локальная база данных
- ✅ **Ktor Client**: HTTP клиент для работы с API
- ✅ **Kotlinx Serialization**: JSON парсинг
- ✅ **ViewModel**: управление состоянием с StateFlow

## Предпочтительный способ запуска — Desktop

### Сборка и запуск

**Требования:**
- JDK 17+
- Gradle 8+

**Шаги:**

1. **Клонируйте репозиторий:**

```bash
git clone <repository-url>
cd adventChallenge
```

2. **Настройте API ключ:**

Создайте или отредактируйте файл `local.properties` в корне проекта:

```properties
zaiApiKey=ВАШ_API_КЛЮЧ_ZAI
openaiApiKey=ВАШ_API_КЛЮЧ_OPENAI
```

> **Примечание:** API ключи можно настроить через интерфейс приложения без редактирования файла конфигурации

3. **Запустите Desktop приложение:**

```bash
./gradlew :desktopApp:run
```

Или используйте Gradle Task:
- `:desktopApp:run` — запуск приложения

4. **Создание дистрибутива (опционально):**

```bash
# Создание установщика для текущей ОС
./gradlew :desktopApp:createDistributable

# Создание всех пакетов (DMG, MSI, DEB)
./gradlew :desktopApp:packageDistributionForCurrentOS
```

Пакеты будут находиться в: `desktopApp/build/compose/binaries/main/`

## Другие способы запуска

## Использование

### Начало работы

1. **Запустите приложение**
2. **Настройте API ключ** через меню настроек (⚙️) или создайте файл `local.properties`
3. **Создайте агента** или выберите из сохраненных
4. **Начните диалог** — введите сообщение в поле ввода

### Работа с агентами

#### Создание агента

1. Нажмите на кнопку с плюсом (➕) в списке агентов
2. Нажмите "Настроить" на карточке агента
3. Заполните параметры агента:
   - **Системный промпт**: описание роли ИИ (например, "Ты эксперт по программированию")
   - **Температура**: 0.0 — консервативные ответы, 2.0 — креативные
   - **Модель**: GLM-4.5-flash (быстрая), GLM-4.6, GLM-4.7
   - **Макс. токены**: ограничение длины ответа (опционально)
   - **Тип ответа**: текст или JSON
   - **Стоп-слово**: слово для остановки генерации (опционально)
4. Сохраните настройки

#### Управление агентами

- **Выбор агента**: нажмите на карточку агента для активации
- **Настройка агента**: нажмите кнопку "Настроить" для изменения параметров
- **Удаление агента**: нажмите кнопку удаления (иконка корзины)
- **Отправка всем**: при наличии нескольких агентов появится кнопка для одновременной отправки

#### Сохранение агентов

Настроенные агенты автоматически сохраняются в базу данных и доступны в будущих сессиях через селектор агентов.

### Работа с сессиями

#### Создание сессии

1. Нажмите на меню настроек (⚙️)
2. Выберите "Создать новую сессию"
3. Имя сессии автоматически обновится на основе первого сообщения

#### Управление сессиями

- **Выбор сессии**: используйте выпадающий список сессий в топбаре
- **Очистка сессии**: нажмите "Очистить" в топбаре для удаления всех сообщений
- **Настройки сессии**: нажмите (⚙️) для настройки сжатия истории
- **Удаление сессии**: доступно через меню настроек

#### Сжатие истории (Summarization)

1. Нажмите на меню настроек (⚙️)
2. В диалоге настроек сессии включите "Сжатие истории"
3. При отправке сообщений длинные беседы будут автоматически сжиматься
4. Суммаризация используется как контекст для будущих запросов

> **Подробнее:** см. [Суммаризация сессий](docs/summarization.md)

### Чат

1. Выберите агента из списка или используйте текущего
2. Введите сообщение в поле ввода
3. Нажмите "Отправить" для запроса к выбранному агенту
4. Или "Отправить всем" для одновременного запроса ко всем агентам
5. Ответы ИИ отобразятся с указанием системного промпта агента

### Дополнительные возможности

#### Копирование сообщений

Удерживайте долгое нажатие на любом сообщении (пользователя или ИИ) для копирования текста в буфер обмена.

#### Отображение токенов

Каждое сообщение показывает:
- **Token Count**: количество токенов в ответе ИИ
- **Outgoing Tokens**: количество токенов в запросе
- **Character Count**: количество символов

#### Управление контекстом

- Сессия показывает общее количество токенов
- Максимальное окно контекста зависит от выбранной модели (200,000 токенов для GLM-4.x)
- При включенном сжатии истории контекст оптимизируется автоматически

## API Endpoints

### z.ai (GLM-4)
- URL: `https://api.z.ai/api/paas/v4/chat/completions`
- Модели:
  - `glm-4.5-flash` — быстрый, 200k контекст
  - `glm-4.6` — стандартный, 200k контекст
  - `glm-4.7` — продвинутый, 200k контекст

### OpenAI (GPT-4)
- URL: `https://api.openai.com/v1/chat/completions`
- Модели:
  - `gpt-4o` — мультимодальная, 128k контекст

## Настройка

### API ключи

**Через файл `local.properties`:**

```properties
zaiApiKey=ваш_ключ_zai
openaiApiKey=ваш_ключ_openai
```

**Через интерфейс приложения:**
1. Нажмите на меню настроек (⚙️)
2. Введите API ключ в соответствующее поле
3. Ключ сохранится в локальном хранилище

### Логирование

Для отладки включено логирование сетевых запросов через Ktor Logging Plugin. Логи выводятся в консоль при запуске приложения.

## Troubleshooting

### Проблемы с API ключами

Если приложение не работает с API:
1. Проверьте, что API ключ правильно указан в `local.properties`
2. Убедитесь, что ключ действителен и имеет необходимый баланс
3. Проверьте соединение с интернетом

### Проблемы с базой данных

Если приложение не сохраняет данные:
1. Проверьте права на запись в директорию приложения
2. Удалите базу данных и перезапустите приложение
3. Проверьте версию JVM/JDK (требуется JDK 17+)

### Проблемы с сборкой

Если Gradle не собирает проект:
1. Очистите кеш Gradle: `./gradlew clean`
2. Удалите `.gradle` директорию
3. Переустановите зависимости: `./gradlew build --refresh-dependencies`
